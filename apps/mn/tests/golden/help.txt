The mn utility creates Mininet network from the command line. It can create parametrized topologies, invoke the Mininet CLI, and run tests.

Usage: mnr [OPTIONS]

Options:
      --switch <SWITCH>               default|ivs|lxbr|ovs|ovsbr|ovsk|user[,param=value...] user=UserSwitch ovs=OVSSwitch ovsbr=OVSBridge ovsk=OVSSwitch ivs=IVSSwitch lxbr=LinuxBridge default=OVSSwitch [default: default]
      --host <HOST>                   cfs|proc|rt[,param=value...] proc=Host rt=CPULimitedHost{'sched': 'rt'} cfs=CPULimitedHost{'sched': 'cfs'} [default: proc]
      --controller <CONTROLLER>       default|none|nox|ovsc|ref|remote|ryu[,param=value...] ref=Controller ovsc=OVSController nox=NOX remote=RemoteController ryu=Ryu default=DefaultController none=NullController
      --link <LINK>                   default|ovs|tc|tcu[,param=value...] default=Link tc=TCLink tcu=TCULink ovs=OVSLink [default: default]
      --topo <TOPO>                   linear|minimal|reversed|single|torus|tree[,param=value...] minimal=MinimalTopo linear=LinearTopo reversed=SingleSwitchReversedTopo single=SingleSwitchTopo tree=TreeTopo torus=TorusTopo [default: minimal]
  -c, --clean                         clean and exit
      --custom <CUSTOM>               read custom classes or params from .py file(s)
      --test <TEST>                   pingall|pingpair|iperf|iperfudp|all|none|build
  -x, --xterms                        spawn xterms for each node
      --dump                          print the planned topology (=== topo === / === dump === / === links === sections, as scripts/diff_topology.sh expects) and exit; works non-root via the dry-run path
  -i, --ipbase <IPBASE>               base IP address for hosts [default: 10.0.0.0/8]
      --mac                           automatically set host MACs
      --arp                           set all-pairs ARP entries
  -v, --verbosity <VERBOSITY>         debug|info|output|warning|warn|error|critical [default: info] [possible values: debug, info, output, warning, warn, error, critical]
      --innamespace                   sw and ctrl in namespace?
      --listenport <LISTENPORT>       base port for passive switch listening [default: 6654]
      --nolistenport                  don't use passive listening port
      --pre <PRE>                     CLI script to run before tests
      --post <POST>                   CLI script to run after tests
      --pin                           pin hosts to CPU cores (requires --host cfs or --host rt)
      --nat [<OPTION=VAL...>]         [option=val...] adds a NAT to the topology that connects Mininet hosts to the physical network. Warning: This may route any traffic on the machine that uses Mininet's IP subnet into the Mininet network. If you need to change Mininet's IP subnet, see the --ipbase option.
      --version                       prints the version and exits
  -w, --wait                          wait for switches to connect
  -t, --twait <WAIT>                  timed wait (s) for switches to connect
      --cluster <server1,server2...>  run on multiple servers (experimental!)
      --placement <block|random>      node placement for --cluster (experimental!) [default: block] [possible values: block, random]
  -h, --help                          Print help
